# SCP - Containment Breach Sandbox Edition

## Russian

### Основное описание

Эта модификация нацелена на добавление расширенных возможностей управления игрой через команды или конфиг-файлы. Основана на [оригинальном репозитории SCP - Containment Breach (ветка dev)](https://github.com/Regalis11/scpcb/tree/dev).

На данный момент **модовая версия полностью несовместима с сейвами модифицированной игры**, даже если при сохранении игры не используются кастомные игровые объекты (предметы, NPC, другое).

Для запуска модифицированной версии используйте файл `SCP - Containment Breach Sandbox Edition.exe`.

[Discord-сервер разработчика (канал scp-containment-breach).](https://discord.gg/ApKpvDuN3S)

[Ссылка на веб-сайт разработчика.](https://evolationstudios.ru/)

### Инструкция по сборке & редактированию

Начиная с версии 1.5.0 в репозитории лежит портативный компилятор BlitzBasic + [4GB Patch](https://ntcore.com/?page_id=371), поэтому вам даже не нужно задумываться об установке Blitz3D IDE.

#### Windows

1. Скачать репозиторий (и распаковать, если был скачан как ZIP-архив).
2. Открыть терминал (PowerShell) / консоль (cmd).
3. Перейти в каталог репозитория игры.
4. Запустить файл `build.bat` (игра будет скомпилирована и пропатчена с использованием [4GB Patch](https://ntcore.com/?page_id=371)).
5. Редактирование файлов возможно как через стандартное IDE (Blitz3D IDE, притом в данном случае компиляция через IDE невозможна если не настроен стандартный компилятор), так и через сторонние редакторы, такие как VS Code, Vim и прочие.
6. См. [Ру-Вики SCP - Containment Breach](https://scpcontainmentbreach.fandom.com/ru/wiki/%D0%9C%D0%BE%D0%B4%D0%B4%D0%B8%D0%BD%D0%B3:%D0%9A%D0%BE%D0%BC%D0%BF%D0%B8%D0%BB%D1%8F%D1%86%D0%B8%D1%8F_%D0%B8%D1%81%D1%85%D0%BE%D0%B4%D0%BD%D0%BE%D0%B3%D0%BE_%D0%BA%D0%BE%D0%B4%D0%B0), если у вас появились проблемы со встроенным компилятором и вы хотите использовать внешний.

#### Linux

1. Используйте Wine или Proton для запуска батника (`build.bat`) и игры.
2. **Ни в коем случае не сохраняйте файлы в Blitz3D IDE (если вы его используете), только открывайте. Это может привести к конфликту символов переноса строк и весь ваш код превратится в кашу.**
3. Чтобы избежать проблем, описанных в пункте 2, используйте для редактирования файлов внешние редакторы (VS Code, Vim, другие).
